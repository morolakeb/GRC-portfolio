# Enterprise GRC & Cloud Security Portfolio

**Author:** Morolake Bolarinwa  
**Portfolio Website:** [morolakebolarinwa.com](https://morolakebolarinwa.com)  
**Focus:** Continuous Compliance Monitoring | IT Audit | Cloud Risk Management | IAM Governance  

## 📌 Executive Summary
This repository contains a collection of professional Governance, Risk, and Compliance (GRC) case files. These artifacts demonstrate the ability to translate complex regulatory requirements (SOC 2, PCI DSS, NIST, ISO 27001) into actionable, technical safeguards across hybrid-cloud environments (Azure, Microsoft Entra ID, Microsoft Sentinel). 

The objective of this portfolio is to showcase practical experience in control design, gap assessments, continuous monitoring, and the creation of defensible, audit-ready evidence.
